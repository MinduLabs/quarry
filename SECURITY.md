# Security Policy

Quarry handles database credentials and production data, so we take security reports seriously.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private vulnerability reporting:
*Security → Report a vulnerability* on https://github.com/MinduLabs/quarry.

We aim to acknowledge reports within 3 days and to ship a fix for confirmed issues as soon as possible.

## Supported versions

Only the latest release receives security fixes during the 0.x series.
